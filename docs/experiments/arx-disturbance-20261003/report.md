# ARX 持续扰动补偿：修改与真实数据验证

日期：2026-10-03。

**本轮实现了稳定 ARX 的因果扰动补偿。蒸馏 B 在五个种子的尾段测试上均有改善，按 Validation 选出的最终模型 RMSE 下降约 63.5%。跨工况误差仍偏大，因此保留为可选实验。**

## 修改内容

原有历史残差初始化只支持 FIR。现在稳定 ARX 也可在预测开始前，用最近历史的一步残差中位数估计持续扰动，并在整个自由仿真区间冻结它：

`A(q)y(t) = B(q)u(t) + c + d`。

其中 `d` 是方程中的扰动，其稳态输出影响为 `d / A(1)`。直接把它作为输出偏移会改变补偿幅度。ARX 的标准方程可见 [MathWorks 官方文档](https://www.mathworks.com/help/ident/ref/arx.html)；历史中位数与冻结规则是本项目的实现选择，效果由下面的实验评价。

- 只使用预测开始前的输出；自由仿真期间使用自身递推输出。未来输入按已知输入轨迹处理。
- 补偿窗口默认三十二个采样点；至少八个有限残差才初始化，历史不足时补偿量为零并记录原因。
- ARX 须稳定；改变预测区间内的输出不能改变预测轨迹。异常历史点用中位数减弱影响。
- 过程系数和训练截距保持冻结，保存模型回放沿用相同策略。新增 ARX 补偿量计入复杂度项。
- 寻优新增 `disturbance_aware`：原一百零二个候选加十八个高阶 Ridge ARX 的补偿版本，共一百二十个候选。使用原时间折、选段策略、反馈动作与随机采样；由 Validation 接纳候选。
- 页面提供“实验：ARX 历史扰动补偿”，手动建模也可设置。报告和模型卡说明历史上下文与扰动持续假设。默认 `established` 保留原候选空间。

这项补偿只处理持续偏差。过程动态系数发生变化时，需要进一步研究分工况模型或过程与扰动的分别建模。

## 评测协议与题目适配

A14 要求流程工业时序数据、数据优选、模型效果反馈和可追溯交付。本轮在真实锅炉、换热器与连续蒸馏数据上执行现有选段和反馈闭环，并测试持久化与交付链路。蒸馏记录来自 [TUM 连续蒸馏公开数据](https://zenodo.org/records/17628963)，包含正常和异常运行的多变量实际测量。

五组此前参与开发的数据作为回归数据；新取两条正常工况记录和一条异常工况记录。三条新记录仍属于同一中试装置，不能解释为三个新工厂。各工况保留物理输入和温度输出，排除标签、报警、状态字段；不拼接不同实验。

- 源数据按时间划分 Train / Validation / Test 为 60% / 20% / 20%，共同历史间隔四十三点。
- 五个随机种子：42、20261003、7、19、31。每种方案每个种子三次 Trial，共保留一百五十次 Trial，闭环统计记录 18,698 次成功的模型/折拟合。该预算仅用于本轮两种方案对照，不与上轮十次 Trial 的成绩作优劣判断。
- 所有种子模型先在隐藏 Test 的数据上完成选择、保存并封存；最终种子按 Validation 得分选择。Test 回放将参数估计函数替换为报错函数，确保没有重新拟合。
- 迁移对照在每个源蒸馏场景的七十八个固定 ARX 候选中，以三折源 Validation 选定结构；再比较相同系数的固定与补偿策略。源 Validation 在目标评分前决定策略。
- 目标预测统一从索引四十三开始，历史补偿窗口三十二点，之后整段自由仿真。三条目标记录均验证了未来输出独立性。
- `protocol.json` 在评分前保存代码、数据和旧证据哈希。脚本曾在不可变对象赋值处失败，修复记录见 `script-repair.json`；当时没有评价 Test 或新目标。已完成的锅炉、换热器结果原样保留，未保存的蒸馏 A 开发步骤重跑。这些重跑不当作独立重复。

## 五组回归数据结果

每个方案的种子均由 Validation 选择。单位采用各数据原始输出单位；表中为整段 Test 自由仿真 RMSE。

| 数据 | 默认方案 | 扰动补偿搜索 | 最终 Test FIT | 结论 |
|---|---:|---:|---:|---|
| 锅炉 | 2.0794 | 2.0794 | 44.44% | 相同 |
| 换热器 | 0.5284 | 0.5284 | 47.41% | 相同 |
| 蒸馏 A | 1.9270 | 1.9270 | −11.47% | 相同，效果不足 |
| 蒸馏 B | 3.3952 | 1.2397 | −32.76% | RMSE 下降 63.5%，效果仍不足 |
| 蒸馏 C | 0.7569 | 0.7569 | −10.82% | 相同，效果不足 |

蒸馏 B 五个种子的默认 / 新方案 RMSE 分别为：3.3952 / 0.9075、6.2999 / 1.4869、4.2529 / 1.2397、6.4845 / 0.5890、3.2710 / 1.2552。全部改善，但这些种子共享同一过程数据，不能视为五个独立工厂。最终模型选种子七，未按 Test 选择误差更小的种子十九。

## 三条新记录：同装置跨工况迁移

| 新记录 | 行数 | 固定 ARX RMSE | 同系数补偿 RMSE | 源 Validation 选择 | 按该选择的 RMSE | 持值 RMSE |
|---|---:|---:|---:|---|---:|---:|
| A / op007 / 异常实验一 | 2,193 | 6.6257 | 6.6248 | 固定 | 6.6257 | 6.9729 |
| B / op007 / 正常实验一 | 548 | 6.4928 | 5.5071 | 补偿 | 5.5071 | 2.7283 |
| C / op002 / 正常实验一 | 385 | 2.0180 | 0.7473 | 固定 | 2.0180 | 0.7269 |

B 的新正常工况按事先选定的补偿策略降低误差约 15.2%，但仍明显差于持值。C 的补偿候选虽然误差下降约 63.0%，源 Validation 选择的是固定策略，因此它的实际迁移选择结果仍为 2.0180。查看目标结果后改选补偿会失去独立评价意义，本轮没有这样做。

A 的异常工况只用于压力测试。其小幅变化不能证明补偿能处理异常原因。三个目标都是一次冻结历史后的长区间预测，没有在目标评分期间反复读输出并校正。

## 当前判断

持续扰动补偿值得保留，蒸馏 B 的结果支持这个方向。其余四组回归数据没有出现最终模型退步，但试验数量和工况范围仍有限。跨工况 B、C 均未达到持值对照水平，下一步应区分持续偏差与动态变化，再评价局部过程模型或 OE / 状态空间模型。

## 复现

在仓库根目录执行。`develop` 拒绝覆盖已经封存的开发结果，需为新实验准备新的输出目录。

```bash
backend/.venv/bin/python backend/scripts/benchmark_arx_disturbance.py prepare --previous docs/experiments/training-policy-20261003 --out 新实验目录
backend/.venv/bin/python backend/scripts/benchmark_arx_disturbance.py develop --out 新实验目录
backend/.venv/bin/python backend/scripts/benchmark_arx_disturbance.py evaluate --out 新实验目录
```

`development.json` 保存全部种子、参数、Trial 和源验证证据；`freeze-seal.json` 封存模型；`test-results.json` 保存全部 Test 回放与新记录结果。旧实验文件保留。
