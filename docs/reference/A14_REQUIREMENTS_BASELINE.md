# A14_REQUIREMENTS_BASELINE

## 1. 赛题名称

A14——基于 Agent 的流程工业建模数据智能优选与闭环寻优系统【和利时】

命题方向：智能计算

题目类别：应用类

---

# 2. 项目核心问题

流程工业中的系统辨识依赖高质量工业时序数据。

真实数据通常存在：

- 大量稳态无效数据；
- 强噪声；
- 缺失值；
- 异常值；
- 多变量强耦合；
- 时间延迟；
- 高共线性；
- 人工数据预处理参数反复试错。

系统需要利用 Agent 把数据处理、模型验证和参数寻优组成自动化闭环。

---

# 3. 最终业务闭环

```text
工业时序数据
        ↓
用户自然语言需求
        ↓
Agent 解析业务意图
        ↓
生成结构化算法工作流
        ↓
数据规整与清洗
        ↓
动态高价值区段筛选
        ↓
时滞估计与补偿
        ↓
共线性检测与变量处理
        ↓
系统辨识模型训练
        ↓
模型评价
        ↓
根据模型评价回溯调整前置处理参数
        ↓
重新执行
        ↓
多轮闭环寻优
        ↓
最佳数据处理策略
        ↓
高质量建模数据
        ↓
模型评估与图文报告
```

---

# 4. 官方核心功能

## 数据管理

支持：

- 多变量工业时序 CSV；
- 上传；
- 查看；
- 删除；
- 基础概览。

必须具有：

**仿真测试集生成工具。**

能够生成：

- 长周期稳态；
- 明确阶跃响应；
- 异常干扰。

---

# 5. 数据规整与清洗

Agent 调度算法完成：

- 异构数据重采样；
- 时间戳对齐；
- 异常值剔除或修复；
- 缺失值处理；
- 必要的数据去噪。

---

# 6. 高信噪比动态数据筛选

要求：

- 无标签数据自动截取；
- 识别富含动态信息的数据；
- 剔除无效稳态平移段；
- 对候选数据段进行质量评分；
- 输出优质建模数据段。

---

# 7. 时滞与共线性

系统需要：

- 计算多变量时间延迟；
- 提供时滞补偿；
- 检测变量共线性；
- 冗余变量剔除或变量合并；
- 支持多变量降维。

---

# 8. 系统辨识

系统需要：

- 对处理后的数据进行快速模型训练；
- 输出系统辨识核心指标。

ARX 是官方举例，不是唯一指定模型。

可以合理增加：

- ARX；
- 线性回归；
- XGBoost；
- Random Forest；
- NARX；
- 状态空间模型等。

但核心仍然是系统辨识和数据优选，不应把项目变成普通机器学习模型平台。

---

# 9. 闭环寻优

核心逻辑：

```text
数据处理参数
→ 数据处理
→ 模型训练
→ 模型评价
→ 调整数据处理参数
→ 再处理
→ 再训练
→ 再评价
→ 选择最佳方案
```

官方要求以辨识效果评价模块输出的指标为目标函数，自动调整前面的数据处理参数。

闭环寻优必须真实执行。

不能使用：

- 固定轮次假数据；
- 固定拟合度；
- 只调模型参数而完全不反馈数据处理；
- 前端模拟寻优过程。

---

# 10. Agent

Agent 是系统的智能中枢。

Agent 应：

- 解析自然语言；
- 理解目标变量；
- 理解输入变量；
- 选择算法；
- 生成结构化工作流；
- 调度底层算法；
- 接收模型评价结果；
- 参与下一轮决策。

推荐架构：

```text
Natural Language
      ↓
Planner
      ↓
Structured Workflow
      ↓
Schema Validation
      ↓
Tool Registry
      ↓
Workflow Executor
      ↓
Algorithm Results
      ↓
Model Evaluation
      ↓
Optimization Feedback
```

禁止让 LLM 不受控制地直接生成并执行任意 Python 代码。

# 11. 推荐底层算法库

- Linear Interpolation
- Forward Fill
- Median Fill

## 异常值

- IQR
- 3 Sigma
- Isolation Forest

## 去噪

- Moving Average
- Median Filter

## 动态区段

- First Difference
- Rolling Variance
- Change Score
- Change Point Detection

## 时滞

- Cross Correlation
- Lag Search

## 共线性

- Pearson
- Spearman
- VIF
- PCA

## 建模

基础：

- ARX

扩展：

- Linear Regression
- Random Forest
- XGBoost

# 12. 推荐模型指标

至少：

- MAE
- RMSE
- R²
- Fit Percentage
- Training Time

时间序列数据不能简单随机打乱。

优先按照时间顺序划分训练、验证和测试数据。

# 15. 当前优先级原则

项目修改时按照：

```text
真实可运行
>
A14 核心闭环
>
算法正确性
>
Agent 智能性
>
量化验证
>
前端展示
>
附加功能
```

不要优先开发：

- 复杂账号系统；
- 消息通知；
- 工厂硬件；
- 实时 PLC；
- 数字孪生；
- 大规模深度学习；
- 与赛题无关的普通后台功能。

---

# 16. 评分基线

A 类企业命题统一初赛评分：

- 项目创意：20
- 实施方案：30
- 技术实现与交付：30
- 项目展示：20

因此，项目优先保证：

- 技术路线清晰；
- 核心功能真实实现；
- 系统可以稳定运行；
- 闭环可以复现；
- 算法结果有量化验证；
- 展示逻辑清晰；
- 文档完整。
