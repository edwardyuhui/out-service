# A14 功能与证据核查（2026-10-04）

本表以赛题任务清单为依据，区分正式产品能力、验证范围与离线实验。功能存在与跨工况效果达标是两个不同的结论。

| 要求 | 正式实现 | 当前验证与边界 |
|---|---|---|
| OR-01 数据上传、管理、概览 | 数据 API、不可覆盖的 CSV 版本与数据页面 | 后端数据生命周期测试；公开锅炉数据实际上传、配置、概览 |
| OR-02 含稳态、阶跃、异常的仿真工具 | `simulation_service.py` 与仿真页面 | S1–S6 和模拟数据生命周期测试；仿真不计入真实工业数据外部验证 |
| OR-03 规整、对齐、重采样、清洗 | `cleaning_service.py`、版本化预处理 | 清洗、异常、对齐测试及前后版本对比；不规则时间轴不能直接当均匀采样辨识 |
| OR-04 无标签动态片段截取、评分、排序 | 质量门控、标准化信息矩阵、唯一行 D-最优优选、集合与时间覆盖 | 真实数据及选段测试；根据 Validation 比较片段方案与全量训练，不预先保证选段更优 |
| OR-05 时滞估计及补偿 | 延迟分析与确认后的补偿版本 | 通道时滞、补偿版本血缘和零延迟 NoOp 测试 |
| OR-06 共线性与冗余处理 | 共线性分析、建议和正式变量剔除 | 特征确认与数据血缘测试；本轮保留被删控制量的工况监测来源，不改变模型特征 |
| OR-07 一键辨识与指标 | 仿射 ARX、OLS/Ridge/Huber、正则 FIR、保存模型、固定参数 Test 回放 | 自由仿真、一步预测、稳定性、残差、持值对照；模型文件保存真实训练支持范围 |
| OR-08 指标反馈到前置参数 | Optuna；实验全折验收中的窗口、片段数、覆盖和窗口方案反馈 | 真实 4 次试验的 Agent 执行中，前三次搜索，第四次执行 Validation 反馈参数；动作前后值与预算状态持久化。未改善保留原最佳模型；欠激励建议真实采集 |
| OR-09 自然语言到工具执行 | DeepSeek 计划、白名单、持久化执行与确认记录 | 真实云端计划驱动 13 步成功执行；报告亦由 DeepSeek 撰写，无回退；隔离数据库记录已授权测试的确认操作 |
| OR-10 图文结论 | 绑定当前执行明确关联证据，含中间版本记录、实际试验曲线和初始/优化/Test 指标 | 真实 Agent 报告 6 类图表、44 项引用全部解析；范围外推和欠激励保留提示，失败试验不提高累计最佳值 |
| OR-11 最终数据导出 | 根据胜出策略重放训练行与权重，CSV 和来源信息 | 导出逐行与原数据比对；全量训练胜出时交付全量有效训练行 |
| OR-12 Web 交互 | 数据、处理、建模、寻优、Agent、报告页面 | 前端完整测试与 TypeScript 检查；本轮新增建模与 Test 工况提示 |

## 本轮证据

- `docs/experiments/feedback-20261004/backend-final-tests.xml`：最终完整后端测试，677 项通过，3 项 Redis 测试单独验证。
- `worker-tests.xml`：隔离 Redis 的真实队列、Worker 往返及超时记录测试。
- `frontend-tests.xml`：完整前端测试。
- `frontend-build.log`：生产构建通过；保留大体积资源块提示。
- `agent-final/agent-integration.json`、`agent-final/artifact-audit.json`：真实 DeepSeek 全流程、保护反馈预算、完整图文报告与 3172 行逐行 CSV 核查。
- `boiler-api-regression/api-integration.json`：真实锅炉上传、清洗 NoOp、寻优、固定参数 Test、实际 CSV 导出、DeepSeek 图文报告。
- `pruning-regression.json`：与上轮冻结模型完全一致，成功结构拟合从 1080 次减少到 704 次；这是计算次数减少，未将运行时间或预测误差改善归因于剪枝。
- `protocol.json`、`development.json`、`freeze-seal.json`、`test-results.json`：此前未评分的真实卷绕过程时间留出验证，两个输出来自同一装置运行，不能算两个独立数据集。

## 尚不能宣称的结果

1. 蒸馏场景的跨运行泛化尚未稳定达到要求；已公布的失败结果继续保留。
2. 没有赛题统一的 FIT 达标阈值。实验验收规则是项目内部规则，不能代替现场控制验证。
3. 多运行共享参数和 OE 是离线实验；不能在演示中当作完整的产品功能。
4. 当前矩阵核查功能闭环。提交资料已在仓库中保存，本轮没有重新录制视频或证明全部答辩材料与当前版本一致。

## 蒸馏后续实验

见 [工作点与局部模型实验](../experiments/local-bank-20261004/report.md)。新的 C 正常运行在第一轮独立检验中失败；之后已作为开发回归，留一运行选模将其 RMSE 从 2.704 降至 1.335，但 FIT 仍为负，B 未改善。局部模型未通过源验证，保持实验能力。多运行训练支持新增运行内/运行间变化证据和实际滞后范围，226 次冻结参数对照完全一致。原有正式功能与默认算法保持原版本，不将这个开发进展当作已完成跨运行泛化。

正式需求来源见 `official-requirements.md` 及赛题手册 A14。新实验完整结论见 [本轮报告](../experiments/feedback-20261004/report.md)。680 项不同后端测试通过（完整测试与单独 Worker 测试取并集），前端 282 项通过；当前代码哈希及原冻结实验哈希检查见 `release-validation.json`。


## 多步 OE 后续实现（2026-10-05 收尾）

新增稳定多步模拟训练，已接入建模 API、前端实验选项及冻结模型回放。独立真实双水箱测试 RMSE 由最初估计器 1.150521 降至 0.719311；当前标准化 24 项对照为 0.760466。属于 SISO 模型部分对照，尚不能证明多输入跨工况泛化。蒸馏 B/C 迁移回归仍失败，默认 Optuna/Agent 策略保持既有 ARX/FIR。OE 不支持软权重，尚未加入自动搜索。

本轮 24 项新增后端测试；718 个不同后端测试和 282 个前端测试均有通过记录（包括失败修复、Redis 独立实例和前端超时补跑）。见 [本轮报告](../experiments/multihorizon-20261004/report.md) 与 [验证清单](../experiments/multihorizon-20261004/release-validation.json)。功能覆盖不能替代泛化效果证明。
