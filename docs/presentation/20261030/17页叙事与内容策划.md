# IndusOpt 工模智优｜10分钟、17页答辩策划

用途：逐页内容与叙事策划，尚未制作PPT。面向现场讲述，以用户任务、真实产品、结果和交付为主。建议口播570秒，预留30秒停顿与切换。封面和结束页计入17页；技术备份不计入主讲。

## 全场主线

工程师拿到一份工业历史数据，面临“数据很多、可用于建模的信息难找”的问题。IndusOpt将数据准备、优选、建模评价与交付串成可追溯流程。用同一份真实锅炉数据贯穿，其他装置只作为补充验证，不把公开数据验证讲成企业现场部署。

## 内容与讲述规则

- 一页一个判断、一个主画面。正文通常不超过3条短句，指标通常不超过2个；确需并列比较时例外。
- 标题尽量直接说出结论，避免通篇使用“项目背景、技术架构、功能介绍”等分类标题。
- 第2—12页持续使用同一份锅炉数据；不要每讲一个功能就换一个案例。
- 第7—10页讲“工程师得到了什么帮助”，技术术语放角落或备注。
- 主讲不单独设置目录页、章节过渡页、技术栈页、公式页，以免占用现场时间。
- 第10页可用20秒左右的既有真实运行录屏替换截图讲述，计入该页40秒，不额外增加演示时间。使用录屏时标明为真实运行录制。
- 第13页的对照口径必须在画面可读，口播简短说明；若显得拥挤，主画面突出双水箱，卷绕作为一句补充，其详细数值移入备份。
- 统一浅底、深绿标题和单一强调色；主图优先真实曲线、平台局部和交付物，避免每页铺满完整后台截图。
